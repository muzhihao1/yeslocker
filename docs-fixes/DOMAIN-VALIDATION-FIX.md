# 🔧 微信小程序域名校验错误解决方案

## 🚨 错误说明

您遇到的错误是：
```
request 合法域名校验出错
http://localhost:8080 不在以下 request 合法域名列表中
```

这是因为微信小程序出于安全考虑，默认只允许访问已配置的 HTTPS 域名。在开发环境中，我们需要关闭这个限制。

## ✅ 立即解决方案

### 步骤1：关闭域名校验

在微信开发者工具中：

1. **点击右上角的"详情"按钮**
   - 或者使用快捷键 `Cmd+,` (Mac) / `Ctrl+,` (Windows)

2. **切换到"本地设置"标签**

3. **勾选以下选项**：
   - ☑️ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

4. **保存并重新编译项目**

### 步骤2：验证后端服务

确保后端服务正在运行：

```bash
# 检查后端是否运行
curl http://localhost:8080/wx/auth/login_by_account

# 或在浏览器访问
http://localhost:8080
```

### 步骤3：启动后端服务（如果未运行）


## 🔍 常见问题排查

### 问题1：后端未启动
**症状**：即使关闭域名校验，仍然无法登录
**解决**：
```bash
# 检查 Java 是否安装
java -version

# 检查端口是否被占用
lsof -i :8080

# 启动后端
./start-backend.sh
```

### 问题2：域名校验设置未生效
**症状**：设置后仍然报域名错误
**解决**：
1. 完全关闭开发者工具
2. 重新打开项目
3. 再次确认设置已勾选
4. 清除缓存：工具 → 清除缓存 → 清除全部

### 问题3：Mock 数据冲突
**症状**：登录成功但数据异常
**解决**：
检查 `src/mock/api.js` 是否启用了 Mock 拦截。开发时可以暂时禁用 Mock。

## 📱 其他开发设置建议

在"本地设置"中，建议同时勾选：
- ☑️ 不校验合法域名
- ☑️ 忽略 getUserInfo 频率限制
- ☑️ 忽略 getUserProfile 频率限制

- 域名校验仅影响开发环境
- 生产环境必须使用 HTTPS 域名
- 本地开发推荐始终关闭域名校验
