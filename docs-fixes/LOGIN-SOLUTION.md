# 🔐 微信小程序登录解决方案

## 📋 问题分析

### 错误信息
```
getUserProfile:fail can only be invoked by user TAP gesture
```

### 原因
从2021年4月起，微信调整了小程序获取用户信息的接口规则：
- `getUserProfile` 必须通过用户主动点击按钮触发
- 不能在页面加载、异步回调等场景自动调用
- 即使是点击按钮，如果代码实现不正确也会失败

## 🚀 解决方案

### 方案1：开发环境测试登录（推荐）✅

#### 已实施的改进
1. **个人资料页面已添加测试登录入口**
   - 文件：`src/pages/user/profile.vue`
   - 仅在开发环境显示"测试登录"按钮
   - 点击后跳转到测试登录页面

2. **使用步骤**
   ```
   1. 重新编译项目：npm run dev:mp-weixin
   2. 在微信开发者工具中刷新
   3. 进入"我的"页面
   4. 点击绿色的"🧪 测试登录"按钮
   5. 使用测试账号登录：
      - 普通用户：user123 / user123
      - 管理员：admin123 / admin123
   ```

### 方案2：直接访问测试页面

1. **编译模式设置**
   - 在微信开发者工具顶部点击"普通编译"下拉框
   - 选择"添加编译模式"
   - 设置：
     - 模式名称：测试登录
     - 启动页面：`pages/test/login`
     - 启动参数：留空
   - 点击确定

2. **快速访问**
   - 在页面路径输入框直接输入：`pages/test/login`
   - 按回车键跳转

### 方案3：生产环境微信登录（需要后续优化）

#### 当前问题
微信已废弃通过button的open-type="getUserInfo"方式，新的登录流程需要：

1. **使用 wx.login 获取 code**
2. **后端通过 code 换取 openid 和 session_key**
3. **使用手机号快速验证（需要企业认证）**

#### 临时解决方案
```javascript
// 修改 utils/wechat.js
export async function wechatLogin() {
  try {
    // 1. 获取登录凭证
    const loginRes = await uni.login({
      provider: 'weixin'
    })
    
    if (!loginRes.code) {
      throw new Error('获取登录凭证失败')
    }
    
    // 2. 直接调用后端接口
    // 不再获取用户信息，由后端处理
    const { data } = await uni.request({
      url: `${getBaseUrl()}/wx/auth/login`,
      method: 'POST',
      data: {
        code: loginRes.code,
        // 可以传递其他必要信息
      }
    })
    
    // ... 后续处理
  } catch (error) {
    console.error('微信登录失败:', error)
    throw error
  }
}
```

## 🛠️ 技术细节

### getUserProfile 限制
- 必须用户主动触发（点击）
- 每次调用都需要用户确认
- 不适合自动登录场景

### 推荐的登录流程
```
1. 静默登录（wx.login）
   ↓
2. 后端创建/更新用户记录
   ↓
3. 返回自定义登录态
   ↓
4. 需要时引导完善信息
```

## 🔧 故障排查

### 如果测试登录按钮不显示
1. 确认是开发环境（NODE_ENV=development）
2. 检查编译是否成功
3. 清除缓存重新编译

### 如果跳转失败
1. 确认 `/pages/test/login` 页面存在
2. 检查 `pages.json` 配置
3. 查看控制台错误信息
