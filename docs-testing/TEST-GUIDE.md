## 常见问题

### 1. 提示"参数不对"
- 确保后端已完全启动
- 使用测试登录功能绕过

### 2. 域名校验错误
- 已在开发者工具中勾选"不校验合法域名"
- 如仍有问题，重启开发者工具

### 3. 后端连接失败
- 等待30秒让后端完全启动
- 检查 MySQL 是否正在运行
- 查看后端日志排查问题
