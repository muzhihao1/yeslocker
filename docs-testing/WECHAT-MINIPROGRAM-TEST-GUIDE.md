# 📱 微信小程序测试指南

## 🚀 快速开始

### 第1步：下载微信开发者工具
1. 访问官网：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 选择对应系统版本（macOS/Windows）下载
3. 安装并打开微信开发者工具
4. 使用微信扫码登录

### 第2步：编译微信小程序
```bash
# 1. 进入项目目录
cd /Users/liasiloam/Library/CloudStorage/Dropbox/项目开发/杆柜管理/yeslocker/yeslocker-uniapp

# 2. 安装依赖（如果还没安装）
npm install

# 3. 编译微信小程序（开发模式）
npm run dev:mp-weixin
```

编译完成后，会在 `dist/dev/mp-weixin` 目录生成小程序代码。

### 第3步：导入项目到微信开发者工具

1. 打开微信开发者工具
2. 点击 "+" 号或 "导入项目"
3. 填写项目信息：
   - **项目名称**：耶氏台球杆存取系统
   - **目录**：选择 `/Users/liasiloam/Library/CloudStorage/Dropbox/项目开发/杆柜管理/yeslocker/yeslocker-uniapp/dist/dev/mp-weixin`
   - **AppID**：使用测试号（点击"测试号"）或留空
4. 点击"导入"

### 第4步：启动后端服务
```bash
# 在另一个终端窗口
cd /Users/liasiloam/Library/CloudStorage/Dropbox/项目开发/杆柜管理/yeslocker
./start-backend.sh
```

确保后端服务运行在 http://localhost:8080

## ⚠️ 注意事项

### 1. 开发环境配置
- **urlCheck关闭**：开发阶段已在project.config.json中关闭域名校验
- **本地测试**：确保后端服务正常运行
- **API地址**：默认配置为 http://localhost:8080

### 2. 常见问题解决

#### Q: 提示"请配置AppID"
A: 开发阶段可以使用测试号或留空，不影响本地测试

#### Q: 网络请求失败
A: 检查：
1. 后端服务是否启动（http://localhost:8080）
2. 开发者工具中"不校验域名"是否勾选
3. API地址配置是否正确

#### Q: 登录功能无法使用
A: 开发环境使用模拟登录，访问 `/pages/test/login` 进行测试

#### Q: 扫码功能无法测试
A: 开发环境可以：
1. 使用输入框手动输入
2. 使用开发者工具的扫码模拟功能
3. 真机预览测试真实扫码
