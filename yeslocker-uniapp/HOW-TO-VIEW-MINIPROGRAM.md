## 查看小程序步骤

### 1. 安装依赖

```bash
cd /Users/liasiloam/Library/CloudStorage/Dropbox/项目开发/杆柜管理/yeslocker/yeslocker-uniapp

# 安装项目依赖
npm install
```

### 2. 运行开发编译

```bash
# 开发模式编译微信小程序（会实时监听文件变化）
npm run dev:mp-weixin

# 或生产模式编译
npm run build:mp-weixin
```

编译后的文件将生成在 `dist/dev/mp-weixin` 或 `dist/build/mp-weixin` 目录。

### 3. 使用微信开发者工具

1. **下载微信开发者工具**
   - 官网：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   - 选择稳定版下载

2. **导入项目**
   - 打开微信开发者工具
   - 选择"小程序" → "导入项目"
   - 目录选择：`/Users/liasiloam/Library/CloudStorage/Dropbox/项目开发/杆柜管理/yeslocker/yeslocker-uniapp/dist/dev/mp-weixin`
   - AppID：可以先使用测试号，或申请真实 AppID

3. **配置 AppID**（可选）
   - 如果有真实 AppID，修改 `src/manifest.json` 中的：
   ```json
   "mp-weixin": {
     "appid": "你的真实AppID"
   }
   ```

### 4. 功能测试指南

#### 首页功能
- 轮播广告展示
- 快速存储/取出入口
- 会员特权展示

#### 存储流程测试
1. 点击"存储球杆"
2. 身份验证（手机号+验证码）
3. 选择储物柜（可按大小筛选）
4. 确认存储信息
5. 生成存储凭证（二维码+数字码）

#### 取出流程测试
1. 点击"取出球杆"
2. 扫描二维码或输入凭证号
3. 查看费用计算
4. 支付（测试环境可跳过）
5. 获取开柜码

#### 用户中心功能
- 个人信息管理
- 存取历史记录
- 会员权益
- 数据统计图表

### 6. 常见问题

**Q: 编译报错怎么办？**
A: 检查 Node.js 版本（建议 14+），删除 node_modules 重新安装

**Q: 开发者工具显示白屏？**
A: 检查基础库版本，建议使用 2.20.0 以上

**Q: 如何测试支付功能？**
A: 开发环境下支付会自动成功，无需真实支付

**Q: 如何查看数据统计？**
A: 用户中心 → 设置 → 开发者选项 → 数据统计
