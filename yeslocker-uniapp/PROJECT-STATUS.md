### 🔧 已知问题及修复

#### 1. 微信登录 600009 错误（已修复）
- **问题**：`errno: 600009 errMsg: "request:fail invalid url"`
- **原因**：微信小程序要求使用完整的URL地址
- **解决方案**：
  - 创建了 `src/config/api.js` 统一管理API地址
  - 添加了环境变量支持（.env.development, .env.production）
  - 更新了登录代码使用配置的API地址
  - 详见：[修复600009错误指南](./docs/fix-600009-error.md)

#### 2. 后端服务启动（已解决）
- **问题**：后端服务未运行导致无法登录
- **解决方案**：
  - Maven已安装在 `/opt/homebrew/bin/mvn`
  - 使用 `mvn clean package -DskipTests` 成功编译项目
  - 后端服务已启动在 http://localhost:8080
  - 进程ID: 31941

### 📱 立即体验

1. **快速启动**
   ```bash
   cd yeslocker-uniapp
   ./quick-start.sh
   ```

2. **手动启动**
   ```bash
   npm install
   npm run dev:mp-weixin
   ```

3. **导入微信开发者工具**
   - 目录：`dist/dev/mp-weixin`
   - 使用测试 AppID 即可
   
4. **开发环境设置**
   - 在微信开发者工具中勾选"不校验合法域名"
   - 确保后端服务已启动（默认 http://localhost:8080）

### 🎯 核心功能演示

#### 存储流程
1. 首页点击"存储球杆"
2. 手机号验证（输入任意11位手机号）
3. 验证码（输入任意6位数字）
4. 选择储物柜（多种尺寸可选）
5. 确认存储信息
6. 获得存储凭证（二维码+数字码）

#### 取出流程
1. 首页点击"取出球杆"
2. 扫码或输入凭证号
3. 查看存储信息和费用
4. 确认支付（自动成功）
5. 获得开柜码
