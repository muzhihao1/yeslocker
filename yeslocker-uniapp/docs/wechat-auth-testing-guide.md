# 微信授权测试指南

本文档帮助开发者理解和测试微信小程序的授权登录流程。

## 1. 开发环境配置

### 1.1 微信开发者工具设置

1. 打开微信开发者工具
2. 进入项目设置 > 本地设置
3. 勾选以下选项：
   - ✅ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书
   - ✅ 不校验小程序的真机调试域名列表

### 1.2 后端 Mock 模式

后端配置文件 `application-dev.yml` 中已启用 Mock 模式：
```yaml
wx:
  mock-mode: true
```

## 2. 测试登录流程

### 2.1 使用测试登录页面

1. 启动小程序
2. 进入"个人中心"页面
3. 在开发环境下会显示"测试登录"按钮
4. 点击进入测试登录页面，可选择不同的测试场景

### 2.2 测试场景说明

#### 新用户 (test-new-user-001)
- 未进行身份验证
- 未分配储物柜
- 需要完成注册流程

#### 已认证用户 (test-verified-user-001)
- 已完成身份验证
- 已分配储物柜（A05）
- 可直接使用存取功能

#### 存储中用户 (test-active-storage-001)
- 当前有球杆存储在柜中
- 显示剩余存储天数
- 可以查看和使用凭证

#### 超期存储用户 (test-expired-storage-001)
- 存储已超过30天
- 需要处理超期情况
- 系统会提醒清理

#### VIP会员 (test-vip-user-001)
- 享有VIP特权
- 专属储物柜
- 延长存储期限

#### 管理员 (test-admin-001)
- 系统管理权限
- 可查看所有储物柜
- 管理用户数据

### 2.3 真机测试

1. 使用真实微信账号登录
2. 系统会调用 `getUserProfile` 获取用户信息
3. 后端 Mock 模式下会返回模拟数据
4. 可测试完整的授权流程

## 3. 常见问题处理

### 3.1 错误 600009

**错误描述**：invalid url / request 合法域名校验出错

**解决方案**：
1. 开发环境：在微信开发者工具中勾选"不校验合法域名"
2. 生产环境：将 API 域名添加到小程序后台的 request 合法域名

### 3.2 getUserProfile 调用失败

**注意事项**：
- `getUserProfile` 必须在用户点击事件后直接调用
- 不能在调用前有任何异步操作（如 showLoading）
- 用户拒绝授权后需要友好提示

### 3.3 Mock 数据不生效

**检查项**：
1. 确认后端配置 `wx.mock-mode: true`
2. 检查请求 URL 是否正确
3. 查看控制台日志 `[SimpleMock]` 开头的信息

## 4. 授权流程图

```
用户点击登录
    ↓
调用 getUserProfile (真机) / 跳过 (开发工具)
    ↓
调用 wx.login 获取 code
    ↓
请求后端 /wx/auth/login_by_weixin
    ↓
Mock 模式返回测试数据
    ↓
保存 token 和用户信息
    ↓
根据用户状态引导后续操作
```

## 5. 调试技巧

### 5.1 查看日志

控制台中查看以下关键日志：
- `[SimpleMock]` - Mock 拦截信息
- `[WeChat Login]` - 登录流程日志
- `[Request]` - API 请求详情

### 5.2 存储调试

使用微信开发者工具的 Storage 面板查看：
- `token` - 登录凭证
- `userInfo` - 用户信息
- `isVerified` - 认证状态

### 5.3 网络调试

使用 Network 面板查看：
- 请求 URL 是否正确
- 请求参数是否完整
- 响应数据格式

## 6. 生产环境注意事项

1. 关闭 Mock 模式
2. 配置正确的 API 域名
3. 在小程序后台配置合法域名
4. 使用 HTTPS 协议
5. 处理真实的微信登录流程
