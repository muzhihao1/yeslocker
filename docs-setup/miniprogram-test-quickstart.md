## 🎯 5分钟快速测试

### 1️⃣ 运行启动脚本（1分钟）
```bash
./test-miniprogram.sh
```

### 2️⃣ 导入项目（2分钟）
1. 打开微信开发者工具
2. 点击 "+" 导入项目
3. 选择目录：`yeslocker-uniapp/dist/dev/mp-weixin`
4. 点击导入

### 3️⃣ 测试核心功能（2分钟）
- ✅ 点击"存杆"测试存储流程
- ✅ 输入凭证码测试取回流程
- ✅ 点击"我的"测试登录功能

## 🚨 遇到问题？

### 后端连接失败
```bash
# 检查后端状态
curl http://localhost:8080/wx/home/index

# 重启后端
./start-backend.sh
```

### 编译错误
```bash
# 清理并重装依赖
cd yeslocker-uniapp
rm -rf node_modules
npm install
npm run dev:mp-weixin
```

### 页面白屏
1. 检查Console是否有错误
2. 确认后端服务正常
3. 清除缓存重新编译
