## 三、技术要点

### 3.1 前端技术栈
- UniApp + Vue.js
- uni-request（HTTP请求）
- Vuex（状态管理）
- uni-ui（UI组件库）

### 3.2 后端技术栈
- Spring Boot（Litemall基础）
- MyBatis
- MySQL 8.0
- Redis（缓存）

### 3.3 关键技术点
1. **WebSocket实时通信**：员工端实时接收新申请
2. **分布式锁**：防止柜子分配冲突
3. **事务处理**：确保申请状态一致性
4. **缓存策略**：提高查询性能
