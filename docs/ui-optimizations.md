# UI优化记录

## 2025-07-26 更新

### 1. 申请流程优化
- **移除审批状态**：申请提交后直接变为"进行中"状态，无需等待审批
- **状态流转**：进行中 → 钥匙归还 → 完成
- **柜子状态联动**：
  - 存杆完成后，柜子状态变为"已占用"
  - 取杆完成后，柜子状态变为"空闲"

### 2. UI界面优化
#### 移除申请编号展示
- 删除了申请详情页的QR码区域
- 不再显示"请将此编号告知工作人员"
- 简化了界面，减少用户困惑

#### 钥匙归还弹窗提醒
- 将钥匙归还提示从页面底部改为弹窗模式
- 页面加载2秒后自动弹出提醒（仅在申请进行中时）
- 用户可通过底部"归还钥匙"按钮手动触发
- 弹窗内容：
  - 标题：🔑 请归还钥匙
  - 内容：存放/取出球杆完成后，请立即将钥匙归还给前台工作人员
  - 按钮：钥匙已归还 / 稍后归还

### 3. 数据一致性优化
#### 创建统一模拟数据文件
- 路径：`/src/utils/mockData.js`
- 提供一致的申请记录数据
- 包含辅助函数：
  - `getRecentRequests()` - 获取最近的申请
  - `getActiveRequest()` - 获取当前活跃申请
  - `getRequestsByType()` - 按类型筛选申请

#### 更新页面使用统一数据
- 申请记录页 (`requests.vue`)
- 储物柜详情页 (`locker/detail.vue`)
- 历史记录页 (`history.vue`)
- 所有页面现在显示一致的：
  - 申请编号格式
  - 时间记录
  - 状态信息
  - 柜子编号

### 4. 状态显示优化
- 新增"进行中"状态显示（橙色标签）
- 状态文案：
  - `active` → "进行中"
  - `completed` → "已完成"
  - `cancelled` → "已取消"
- 移除了"待处理"状态

### 5. 代码结构改进
- 集中管理模拟数据，避免分散在各个页面
- 统一了日期时间格式化函数
- 优化了状态管理逻辑
- 改进了页面间的导航和数据传递
