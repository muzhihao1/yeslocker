# 耶氏台球杆存取系统 - 新流程实现总结

## 业务流程变更

### 原流程（自助式）
- 用户存杆时选择空闲柜子
- 生成二维码凭证
- 扫码自助取杆

### 新流程（申请制）
- 用户注册时选择专属柜子（永久绑定）
- 每次存取发起申请
- 服务员验证身份后给钥匙
- 用户自行操作后归还钥匙

## 实现的主要修改

### 1. 数据库更新
- 新增 `locker-new-flow.sql` 文件
- 用户表增加 `locker_id` 字段（专属柜子）
- 新增申请表 `litemall_storage_request`
- 新增员工操作日志表 `litemall_staff_log`

### 2. 首页改造
- 显示用户的专属柜子信息（如A12）
- 移除扫码功能
- 改为"申请存杆"和"申请取杆"按钮
- 新增快捷入口：我的柜子、申请记录等

### 3. 新增页面
- `/pages/storage/request.vue` - 申请页面
- `/pages/storage/request-detail.vue` - 申请详情
- `/pages/storage/requests.vue` - 申请记录列表
- `/pages/locker/detail.vue` - 我的储物柜详情

### 4. 申请流程
1. 用户点击"申请存杆/取杆"
2. 确认个人信息和柜子信息
3. 提交申请（无需审批，直接进行中）
4. 到前台出示申请单
5. 服务员验证身份并给钥匙
6. 用户操作完成后归还钥匙
7. 在系统中确认钥匙已归还，完成流程

## 核心变化总结

1. **从自助到人工**：取消了自助扫码，改为人工审核
2. **从临时到固定**：用户有专属柜子，不再每次选择
3. **从凭证到申请**：不再生成二维码凭证，改为申请单模式
4. **身份验证加强**：每次操作都需要服务员验证身份

这种模式更适合需要严格管理和人工监管的场景。
