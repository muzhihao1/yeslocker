# 部署前检查清单

在开始部署前，请确保已经完成以下准备工作：

## 1. 资源准备 ✓

### 服务器
- [ ] 已购买云服务器（最低配置：2核4G）
- [ ] 服务器操作系统：Ubuntu 20.04 LTS 或 CentOS 7.x
- [ ] 已获取服务器的公网IP地址
- [ ] 已设置服务器的root密码或SSH密钥
- [ ] 已配置安全组规则（开放端口：22, 80, 443, 8080）

### 域名
- [ ] 已购买域名
- [ ] 域名已完成ICP备案（国内服务器必须）
- [ ] 已将域名解析到服务器IP
- [ ] DNS解析已生效（ping域名能返回服务器IP）

### 微信小程序
- [ ] 已注册微信小程序账号
- [ ] 小程序已完成企业认证
- [ ] 已获取AppID
- [ ] 已获取AppSecret
- [ ] 已在小程序后台配置服务器域名（部署后）

## 2. 代码准备 ✓

### 后端代码
- [ ] 已完成后端代码开发
- [ ] 本地测试通过
- [ ] 已编译生成JAR包：`litemall-all-0.1.0-exec.jar`

### 管理后台
- [ ] 已完成管理后台开发
- [ ] 已修改生产环境API地址
- [ ] 已编译生成静态文件（dist目录）

### 小程序代码
- [ ] 已完成小程序开发
- [ ] 已修改生产环境API地址
- [ ] 已使用HBuilderX或uni-app编译为微信小程序代码

## 3. 数据库准备 ✓

## 7. 部署步骤概览

1. **环境准备**（30分钟）
   - 登录服务器
   - 安装JDK、MySQL、Nginx等

2. **数据库部署**（15分钟）
   - 创建数据库
   - 导入SQL文件

3. **后端部署**（20分钟）
   - 上传JAR包
   - 配置application.yml
   - 创建系统服务

4. **前端部署**（15分钟）
   - 上传管理后台文件
   - 配置Nginx

5. **SSL配置**（10分钟）
   - 申请Let's Encrypt证书
   - 配置HTTPS

6. **小程序发布**（30分钟）
   - 上传代码到微信
   - 配置服务器域名
   - 提交审核
