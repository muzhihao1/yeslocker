# 扫码取物功能集成指南

## 功能概述

本文档描述了扫码取物功能的完整实现，包括：
- QR码扫描功能
- 凭证验证API对接
- 取物流程UI交互
- 错误处理机制

## 主要组件

### 1. 首页扫码入口
- **文件**: `src/pages/home/index.vue`
- **功能**: 添加了"扫码取杆"快捷入口
- **方法**: `startScanForRetrieve()` - 调用微信扫码API并跳转到取物页面

### 2. 取物流程组件
- **文件**: `src/components/molecules/RetrievalFlow.vue`
- **功能**: 完整的取物流程实现
- **特性**:
  - 支持扫码和手动输入两种方式
  - 自动格式化凭证码输入（XXXX-XXXX-XXXX）
  - 显示最近的存储记录
  - 凭证验证和确认流程
  - 成功页面展示

## 用户流程

1. **扫码取物**:
   - 用户点击首页"扫码取杆"按钮
   - 调用微信扫码功能
   - 自动识别凭证二维码
   - 跳转到取物确认页面

2. **手动输入**:
   - 用户进入取物页面
   - 切换到"手动输入"标签
   - 输入12位凭证码
   - 点击"验证凭证"

3. **快速选择**:
   - 系统显示最近3条活跃存储记录
   - 用户点击记录快速填充凭证码

4. **确认取物**:
   - 验证凭证成功后显示详细信息
   - 检查是否有超期费用
   - 用户确认后完成取物

## 错误处理

### 凭证验证失败
- 凭证码无效：提示"凭证码无效，请检查输入是否正确"
- 凭证已使用：提示"该凭证已被使用"
- 凭证已过期：提示"凭证已过期"
- 网络错误：提示"网络连接失败，请检查网络设置"

### 扫码失败
- 用户取消：静默处理，不显示错误
- 权限未授权：引导用户到设置页开启相机权限
- 扫描非凭证码：提示"请扫描储物凭证二维码"

## 安全考虑

1. **凭证码格式验证**：
   - 必须是12位大写字母和数字
   - 自动去除输入中的连字符和空格

2. **API调用保护**：
   - 所有API调用需要携带用户token
   - 验证失败自动跳转登录

3. **本地存储清理**：
   - 取物成功后自动清除本地凭证缓存
   - 更新活跃凭证列表
